# 自动壁纸（ChangeWallpaper）

一款使用 Kotlin 和 Jetpack Compose 开发的 Android 自动壁纸应用。添加一个或多个图片文件夹后，应用会按照设定的方式和时间间隔自动更换壁纸。

## 功能

- 使用 Android 系统文件夹选择器，无需申请整个存储空间的访问权限
- 支持多个相册、子文件夹扫描和图片预览
- 主屏幕与锁定屏幕可使用不同相册
- 支持顺序、随机、随机不重复三种轮播模式
- 支持填满、完整显示和柔焦背景三种图片适配方式
- 支持按分钟、小时或天设置切换间隔
- 支持更换主屏幕、锁定屏幕或两者
- 支持上一张、下一张、随机更换和排除指定图片
- 支持每日生效时间段和可选结果通知
- 自动跳过无法解码或损坏的图片
- 保存最近 50 条更换历史
- 支持浅色、深色和多套主题颜色
- 支持设置导入与导出
- 长按应用图标可以立即或随机更换壁纸
- 支持添加“一键换壁纸”桌面快捷方式
- 使用 WorkManager 在后台可靠调度任务
- 使用 DataStore、ViewModel 和 StateFlow 管理响应式状态

## 环境要求

- Android 7.0（API 24）及以上
- Android Studio / JDK 11 及以上

## 构建

```bash
./gradlew :app:assembleDebug
```

生成的 APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。

## 使用说明

1. 在“相册”中添加存放壁纸图片的文件夹。
2. 选择主屏幕和锁定屏幕使用的相册，可点击预览图排除图片。
3. 在主页设置轮播方式、显示方式、切换间隔和应用范围。
4. 开启“自动更换”。

长按桌面上的应用图标可使用快速更换操作；也可以在“设置”中添加独立桌面快捷方式。

Android 的可靠周期后台任务最短间隔为 15 分钟，实际执行时间可能受设备省电策略影响。

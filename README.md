# 自动壁纸（ChangeWallpaper）

一款使用 Kotlin 和 Jetpack Compose 开发的 Android 自动壁纸应用。添加一个或多个图片文件夹后，应用会按照设定的方式和时间间隔自动更换壁纸。

## 功能

- 更换前识别系统桌面；游戏、其他应用、锁屏、未授权或前台不明确时跳过更换

- 支持从 `https://wallpaper.wonyoung.top` 定时下载并更换壁纸
- 支持多设备同步、独立轮换和随机三种网络模式，默认每 5 分钟检查服务端
- 网络图片默认可通过 Wi-Fi 或移动数据下载
- 图库统一提供网络与本地入口，支持分页浏览和图片加载失败重试
- 网络与本地图片均支持全屏预览、选择应用范围和显示方式，并将指定图片设为壁纸
- 预览按屏幕比例复用壁纸渲染逻辑，支持从本地图片预览中排除轮播并撤销
- 使用 Android 系统文件夹选择器，无需申请整个存储空间的访问权限
- 支持多个相册、子文件夹扫描和图片预览
- 主屏幕与锁定屏幕可使用不同相册
- 支持顺序、随机、随机不重复三种轮播模式
- 按实际屏幕尺寸采样缩放，校正完整 EXIF 旋转与镜像方向
- 支持智能适配、居中裁剪、完整显示和柔焦背景，横竖图均无纯黑补边
- 支持按分钟、小时或天设置切换间隔
- 支持更换主屏幕、锁定屏幕或两者
- 支持上一张、下一张、随机更换和排除指定图片
- 支持每日生效时间段和可选结果通知
- 自动跳过无法解码或损坏的图片
- 保存最近 50 条更换历史
- 支持横屏侧边导航、首页与设置双列布局、图库自适应列数和左右分栏预览，旋转后保留页面与预览选择
- 支持浅色、深色和多套主题颜色
- 支持设置导入与导出
- 长按应用图标可以立即或随机更换壁纸
- 支持添加“一键换壁纸”桌面快捷方式
- 使用 WorkManager 在后台可靠调度任务
- 使用 DataStore、ViewModel 和 StateFlow 管理响应式状态

## 环境要求

- Android 7.0（API 24）及以上
- Android Studio / JDK 11 及以上

## 构建

```bash
./gradlew :app:assembleDebug
```

生成的 APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。

## 使用说明

1. 在主页展开“轮播设置”，选择“网络图库”或“本地相册”作为壁纸来源。
2. 使用网络来源时选择同步、独立轮换或随机模式；也可以在“图库”中预览服务端图片。
3. 使用本地来源时，在“图库 → 本地相册”中添加文件夹，通过相册的“管理”选择主屏幕和锁屏相册。
4. 在主页的“轮播设置”中设置显示方式、切换间隔和应用范围，然后开启“自动更换”。
5. 点击任意网络或本地图片进入预览，选择本次应用范围和显示方式后设为壁纸。本次选择不会修改自动轮播配置。
6. “设置”中可选择每日生效整点、图库布局和主题颜色，低频的接口网址与备份配置位于页面下方。

长按桌面上的应用图标可使用快速更换操作；也可以在“设置”中添加独立桌面快捷方式。

应用使用连续单次后台任务实现最短 5 分钟的检查间隔；实际执行时间仍可能受设备省电策略影响。

## 仅桌面更换保护

在主页或设置页的“桌面保护”中开启系统“使用情况访问权限”。应用通过 HOME Intent 获取桌面包名，并读取 UsageEvents 判断前台活动；权限未授予、屏幕关闭、设备锁定、前台未知或多个应用同时处于 resumed 状态时，不更换壁纸。

保护覆盖自动任务、手动换图、指定网络或本地图片，以及桌面快捷方式。应用内手动提交也会跳过；请返回桌面等待下一次自动检查，或使用桌面快捷方式（退出快捷操作页后约 2 秒开始检查）。跳过不会排除图片或记录成图片失败，自动任务仍按原间隔安排下一次检查，回桌面不会立即触发更换。

任务开始、下载后进入渲染时，以及每次调用系统设置壁纸接口前均重新检查。前台判断使用系统使用事件，可能受到厂商事件延迟影响；检查与系统调用无法原子完成，因此这是一层保护措施，不能据此确认游戏闪退的根因已消除。
